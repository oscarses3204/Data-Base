PART 1: MONGODB DATABASE CREATION
In the SQL script file mqlCreatedb.sql, construct, using the Oracle SQL/JSON functions presented in the course,
SQL statements that create JSON collections for a MongoDB database with the structure indicated below from
a relational database whose relation schemas are those specified in the msmsSampledb.sql script file. In all
created collections, a field whose value is null should be absent in objects/arrays of the collection.
The following is an example of an object in the moviePersons collection.
