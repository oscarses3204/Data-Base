ANALYTIC FUNCTIONS
l

An analytic function computes an aggregate value for the query
result, possibly based on a grouping of tuples of the query result
called a partition.

☞ Unlike an aggregate function, an analytic function
can return multiple tuples for each group.

l

l

Within a partition, a sliding window of tuples can be used to
determine the range of tuples used to perform the calculations
for the current tuple of the query result.
An analytic function is the last set of operations performed in a
query except for the final order by clause.

☞ Consequently, an analytic function can appear only in
the select clause or final order by clause.

Applications: sales-trend analysis, stock-market trend analysis, etc.

ORACLE ANALYTIC FUNCTION SYNTAX
analytic_function([arguments])
over ([partition by clause] [order by clause [windowing_clause]])
analytic_function – a function that computes an aggregate value over a group of tuples
(e.g., avg, sum, rank, percentile rank, nth value, linear regression, etc.).

partition by clause – optional; partitions the query result into groups based on one or
more criteria (like a group by clause). If this clause is omitted, then the function
treats all tuples of the query result as a single group.

select accountNo, balance, branchName,
sum(balance) over (partition by branchName) as totalBranchBalance
from Account;
order by clause – optional; specifies how data is ordered within a partition.

select accountNo, balance, branchName,
sum(balance) over (partition by branchName order by accountNo)
as totalBranchBalance
from Account;
A group by clause is applied to the result of the from and where clauses. A partition by

RANK FUNCTION: NOTES
– Null values are normally treated as the highest values.
Ø Can be changed using nulls first or nulls last keywords.

– Multiple rank expressions can be used within a single select statement
(e.g., overall rank and rank within a department).
– When ranking occurs along with a group by clause, the group by clause is
applied first and ranking is done on the results of the group by.
– Several other functions can be used in place of rank.
Ø precent_rank – gives the rank of a tuple as a fraction (defined as (r-1)/(n-1)
where n is the number of tuples and r is the rank of the tuple).
Ø cume_dist – gives the cumulative distribution for a tuple (defined as p/n where
p is the number of tuples with ordering values preceding or equal to the
ordering value of the tuple and n is the number of tuples).
Ø row-number – sorts the rows and gives each row a unique row number based
on its position in the ordering; rows with the same ordering value get different
row numbers in a nondeterministic fashion.

DENSE_RANK FUNCTION
l

The rank function gives the same rank to all tuples that have
equal value on the order by attributes.
– E.g., if two branches have the same highest asset value, both would
get rank 1.

l

This results in "gaps" in the ranking
– E.g., if two branches have the top rank of 1, then the next rank
would be 3, not 2.

l

The dense_rank function eliminates gaps in the ordering; ties still
get the same rank.

l

l

A common ranking type of query is to determine the percentile
in which a value in a multi(set) belongs (e.g., top, bottom half;

LISTAGG FUNCTION SYNTAX AND NOTES
listagg ([all | distinct] column_name [, delimiter])
[within group(order_by_clause)]
[over(query_partition_clause)]
all | distinct – all (the default) retains all values; distinct removes duplicate values.
column_name – a column, constant, or expression that involves the columns.
delimiter – a string that separates the result values. If delimiter is omitted, the
function uses a null value (i.e., no delimiter).

order_by_clause – a list of sort expressions to sort the list values in ascending (asc)
or descending (desc) order. The nulls first or nulls last option can be used to
control the sort order of nulls. The defaults are ascending order and nulls last.
As a single-set aggregate function, listagg operates on all result tuples and returns a
concatenated string containing all column_name values as a single tuple.
As a group-set aggregate function, listagg operates on and returns an output tuple
for each group defined by the group by clause.
As an analytic function, listagg partitions the query result into groups based on the
query_partition_clause.

WINDOWING
analytic_function([arguments])
over ([partition by clause] [order by clause [windowing_clause]])
l

A windowing clause allows an analytic function to be computed
over a moving partition called a window.

☞ Useful for computing an aggregate over a fixed time range.
l

l

l

The window moves (slides) over the tuples of a query result,
and, for each tuple, the window is used to calculate the function
result.
A start point, end point or both for the window can be specified
either in terms of the number of tuples in the window (a physical
set) or in terms of a range (a logical offset).
Unlike partitions, windows may overlap so that a tuple may
contribute to multiple windows.

ORACLE WINDOWING_CLAUSE SYNTAX

rows | range – defines for each row in a partition a window either of rows (i.e., a
physical unit) or a range (i.e., a logical offset) used for calculating the function
result. The function is then applied to all the rows in the window which moves
through the partition from top to bottom.

between … and – specifies a start point (expression before and) and end point
(expression after and) for the window.

unbounded preceding – indicates that the window starts at the first row of the partition.
unbounded following – indicates that the window ends at the last row of the partition.

current row – specifies that the window begins at the current row (if rows is specified)
or value (if range is specified).

3.9.2

TUPLE INSERTION
l

The insert command adds one or more tuples to a relation.

Example: Add a new account.
insert into Account values ('A-332', 1200 , 'Pacific Place');

Example: Add a new account with balance set to null (if allowed).
insert into Account values ('A-333', null, 'Pacific Place');

☞ The order of the values must match the order
