STRUCTURED QUERY LANGUAGE (SQL)
l

SQL is used in all commercial relational database systems.
– It is an American National Standards Institute (ANSI) standard.

– Not all relational database systems implement all language features
of the ANSI standard or implement them according to the ANSI
standard.
– Many relational database systems also include additional language
features that are not part of the ANSI standard.

l

SQL is composed of a

– data definition language (DDL) used to specify relation schemas.

– data manipulation language (DML) used to query and change data
in a relational database.

STRING PATTERN MATCHING:
REGEXP_LIKE OPERATOR (cont’d)
Usage: regexp_like(source_string, pattern, [match_parameter])
where:

– source_string is a search value (usually an attribute name);
– pattern is a regular expression;

– match_parameter specifies a matching behaviour as follows

Ø 'i' specifies case-insensitive matching.
Ø 'c' specifies case-sensitive matching.
Ø 'n' allows the period (.), which is normally the match-any-character
wildcard character, to match the newline character.
Ø 'm' treats the source string as multiple lines.
If match_parameter is omitted, then:
o The default case sensitivity is used (usually case-sensitive).
o A period (.) does not match the newline character.
o The source string is treated as a single line.

For information on the regular expressions supported by Oracle see https://docs.oracle.com/cd/B12037_01/server.101/b10759/ap_posix001.htm#i690819.

CONDITIONAL LOGIC: CASE STATEMENT
The case statement evaluates a list of when clauses and returns the
value of the first when clause that evaluates to true.
Ø If no when clause evaluates to true, the else clause value is returned.

Ø If neither the else clause nor any when clauses are true, null is returned.

Ø A case statement can be used anywhere a value is expected (e.g., it can
be used in a predicate in a where clause).

Query: For each client categorize their credit rating as follows:
between 1 and 3, high risk; between 4 and 7, medium risk;
between 8 and 10, low risk otherwise unknown risk.
select name, case
when rating <= 3 then 'high risk'
when rating <= 7 then 'medium risk'
when rating <= 10 then 'low risk'
else 'unknown risk'
end as rating
from Client;
