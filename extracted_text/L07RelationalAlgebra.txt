l

Our
focus

Two mathematical query languages form the basis for “real”
relational query languages (e.g., SQL) and for implementation.
Relational Procedural (step-by-step).
Algebra
Need to describe how to compute a query result.
Relational Non-procedural (declarative).
Calculus
Only need to state what query result is wanted, not
how to compute it.

☞ Relational algebra is very useful for representing and
optimizing query execution plans.
(Discussed later in the course.)

Understanding relational algebra is the key
to understanding SQL and how it is processed!

2.6

RELATIONAL ALGEBRA
l

The relational algebra is an algebra whose
– operands are either relations or variables that represent relations.
– operations perform common, basic manipulations of relations.

Closure Property
l

Relational algebra is closed with respect to the relational model.

☞ Each operation manipulates one or more

relations and returns a relation as its result.

Due to the closure property, operations can be composed!

☞ A relational algebra expression is evaluated from the inside-out.

SET OPERATIONS
l

The set operations, each of which takes two input relations, are:
∪

union

−

set difference remove common tuples from the first input relation

∩

intersection

merge tuples from both input relations

keep only the tuples common to both input relations

(Intersection is not basic; it can be expressed using union and set-difference,
i.e., r ∩ s = (( r ∪ s) − (r − s)) - (s -r)).
l

The two input relations must be union-compatible, which means
that
– the relations have the same number of attributes.
– corresponding attributes have the same data type.

l

The output is a single relation (without duplicates).

OUTER JOIN
l

l

l

An extension of the natural join operation that avoids loss of
information.
Computes the natural join and then adds tuples from one input
relation that do not have matching tuples in the other input
relation to the join result.
Uses null values to fill in missing information.
– Recall that null signifies that the value is unknown or does not exist.

☞ All comparisons involving null are false.
(In particular, null=null is false.)
