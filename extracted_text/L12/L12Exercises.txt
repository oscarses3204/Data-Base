EXERCISE 1
Construct a JSON object for each tuple in the Sailor
relation with fields all the Sailor relation attributes; a
field whose value is null should be absent.
Order the query result objects by sailor id ascending.
select json_object(
'sailorId' value sailorId,
'sName' value sName,
'hkid'
value hkid,
'rating' value rating,
'age'
value age
absent on null)
from Sailor
order by sailorId;

Recall
The default behaviour for
json_object is null on null.

The rating field will be absent for sailors whose rating is null.

object containing, as its fields, the field boat id and its value
for each boat that the sailor has reserved; if a sailor has no
reservations, then the "reservations" field should be absent.

correct
solution?

Why?

absent on null)

The query result contains all reservations made by a sailor, but the reservations field will be present
for all sailors with an empty reservations object for those sailors who have no reservations.

EXERCISE 5
Construct a JSON object for each sailor who has reserved a
boat with fields sailor id, name and reservations which is an
array field whose values are objects, one for each of the sailor's
reservations, with fields boat id, boat name and boat type.
Order the query result objects by sailor id ascending.
select json_object(
'sailorId'
value sailorId,
'sName'
value sName,
'reservations' value json_arrayagg(json_object('boatId' value boatId,
'bName' value bName,
'bType' value bType)))
from Sailor natural join Reserves natural join Boat
group by sailorId, sName
order by sailorId;

EXERCISE 7
Construct a JSON object for each sailor with fields all the
attributes of Sailor and reservations which is an array field whose
values are objects, one for each of the sailor's reservations, with
fields boat id and reservation date. If a sailor has not reserved
any boat, then the "reservations" field should be absent.
The reservation date format should be the same as in the
Reserves relation, i.e., DD-MON-YY.
select json_object(
'sailorId'
value sailorId,
'sName'
value sName,
'hkid'
value hkid,
'rating'
value rating,
'age'
value age,
'reservations' value (select json_arrayagg(json_object('boatId' value boatId,
'rDate' value to_char(rDate,'DD-MON-YY')))
from Reserves R
where R.sailorId=S.sailorId)
absent on null)
from Sailor S;
