Q U E R Y IN G A R R A Y S
l

Array elements can be accessed by their position in the array
using dot notation.

Ø The array name is concatenated with a dot (.), a zero-based index position
and a field name all of which are enclosed in quotes.

Query: Find the name and loan information for the clients whose
first loan amount is less than $50,000.
db.clients.find({'loans.0.amount': {$lt: 50000}},
{_id: 0, name: 1, loans: 1});
Query {name: 'Mary Kwan', loans: [{loanNo: 'L-321', amount: 40000, year: '2024', branch: 'Pacific Place'},
result:
{loanNo: 'L-434', amount: 52000, year: '2025', branch: 'Festival Walk'}]}

The query searches for documents with a loans
array field whose first element (i.e., the element
at index position 0) is an object with an amount
field that is less than $50,000.

Note that a query result document may have
additional loans (e.g., loan L-434) with an amount
field that is greater than or equal to $50,000.

QUERYING ARRAYS (cont'd)
l

The fields of documents in an array can be accessed by name
using the dot notation.

Ø The array name is concatenated with a dot (.) and the field name all of which
are enclosed in quotes.

Query: Find the name and loans of clients where the client has a
loan with amount greater than $75,000.
db.clients.find({'loans.amount': {$gt: 75000}},
{_id: 0, name: 1, loans: 1});
Query {name: 'Steven Chan', loans: [{loanNo: 'L-171', amount: 90000, year: '2024', branch: 'Star House'},
result:
{loanNo: 'L-435', amount: 55000, year: '2025', branch: 'Festival Walk'}]}

The query searches for documents with a loans array field that contains at least one
element (i.e., at least one object) where the amount field is greater than $75,000.
Note that a query result document may also have other loan array objects with an
amount field that is less than or equal to $75,000 (e.g., loan L-435).

☞ Equality matches to select a specific array element require an
exact match of the element on all fields including field order.

Q U E R Y IN G A R R A Y S :
T H E $ N E C O M P A R IS O N O P E R A T O R
Query: Find the name and loans of clients where the client has a
loan with amount not equal to $55,000.
db.clients.find({'loans.amount': {$ne: 55000}},
{_id: 0, name: 1, loans: 1});
Query {name: 'Mary Kwan', loans: [{loanNo: 'L-321', amount: 40000, year: '2024', branch: Pacific Place'},
result:
{loanNo: 'L-434', amount: 52000, year: '2025', branch: 'Festival Walk'}]}
{name: 'Isaac Li'}

This query searches for documents where the loans array field contains at least one
element (i.e., at least one object) whose amount field is equal to $55,000 and
removes that document from the query result even though the loans array field may
contain other objects whose amount field is not equal to $55,000 (e.g., Steven Chan).
While this may seem counterintuitive, it makes sense if we consider that the query

db.clients.find({'loans.amount': {$eq: 55000}},
{_id: 0, name: 1, loans: 1});
returns documents where the loans array field contains at least one element (i.e., at
least one object) whose amount field is equal to $55,000. Using similar semantics, the
$ne operator removes documents where the loans array field contains at least one
element (i.e., at least one object) whose amount field is equal to $55,000.

A R R A Y Q U E R Y O P E R A T O R : $ E LE M M A T C H
arrayField: {$elemMatch: {predicate1, predicate2, …, predicaten}
The $elemMatch operator matches documents that contain arrayField and this
array has at least one element that satisfies all the specified predicates.

Ø If arrayField is not an array but it matches the query conditions, then it is not included
in the query result.

☞ $elemMatch can only be used to match array elements.
Query: Find the name and loans of clients where the client has a loan
at the Festival Walk branch with amount greater than $50,000.
db.clients.find({loans: {$elemMatch: {amount: {$gt: 50000},
branch: 'Festival Walk'}}},
{_id: 0, name: 1, loans: 1});
Query {name: 'Steven Chan', loans: [{loanNo: 'L-171', amount: 90000, year: '2024', branch: 'Star House'},
result:
{loanNo: 'L-435', amount: 55000, year: '2025', branch: 'Festival Walk'}]}
{name: 'Mary Kwan', loans: [{loanNo: 'L-321', amount: 40000, year: '2024', branch: Pacific Place'},
{loanNo: 'L-434', amount: 52000, year: '2025', branch: 'Festival Walk'}]}
{name: 'Pam Du', loans: [{loanNo: 'L-435', amount: 55000, year: '2025', branch: 'Festival Walk'}]}

ARRAY QUERY OPERATOR: $ELEMMATCH (cont'd)
The $elemMatch operator can be used in a find method projection to return
only those query result array elements that match the specified predicate.

☞ Only the first element in the query result array
that matches the predicate is returned.

Query: Find the name of clients who have a loan amount greater
than $50,000 and include one of these loans in the result.
db.clients.find({'loans.amount': {$gt: 50000}},
{_id: 0, name: 1, loans: {$elemMatch: {amount: {$gt: 50000}}}});
Query {name: 'Steven Chan', loans: [{loanNo: 'L-171', amount: 90000, year: '2024', branch: 'Star House'}]}
result: {name: 'Mary Kwan', loans: [{loanNo: 'L-434', amount: 52000, year: '2025', branch: 'Festival Walk'}]}
{name: 'Pam Du', loans: [{loanNo: 'L-435', amount: 55000, year: '2025', branch: 'Festival Walk'}]}

This query finds all clients with loans whose amount is greater than $50,000 and returns
only the first loan (i.e., the first element) in the loans array field whose amount is greater
than $50,000 for each client. Other loans of a client whose amount also matches the
$elemMatch predicate are not in the query result (e.g., loan L-435 for Steven Chan).
Note that if the find filter condition is omitted, then all clients are returned and those with
no loan greater than $50,000 will display only the name (e.g., Isaac Li).

A R R A Y Q U E R Y O P E R A T O R : $ A LL
arrayField: {$all: [value1, value2, …, valuen]}
The $all operator selects the documents where arrayField is an array of
values and the array contains all the elements specified in the array of

db.clients.find({tags: {$all: ['vip', 'senior']}},

☞ $all is equivalent to $and of the specified values.

The $arrayElemAt operator returns the array element at the specified index.
Ø The first array element is at index zero.
Ø If index is zero or a positive integer, the element at the index position counting
from the start of the array is returned.
Ø If index is a negative integer, the element at the index position counting backward
from the end of the array is returned.
Ø if index exceeds the array bounds, no result is returned.
Ø If array is absent, null is returned.

ARRAY EXPRESSION OPERATORS: $FILTER (cont'd)
$filter: {input: array, as: variableName, cond: predicate, limit: integer}
The $filter operator selects only those elements in array that match the
specified predicate and returns them in an array.

Ø If array is null or absent, null is returned.
Ø The as field is optional; variableName represents each individual element of array
and can be used to refer to the array element currently being processed using a
$$ prefix (i.e., $$variableName). If the as field is absent, variableName defaults to this.
Ø The limit field is optional; it restricts the number of matching array elements to
return to at most integer.
Ø The returned array elements are in the original order.
🙁🙁 An error is raised if input is not an array. 🙁🙁

O R D E R IN G Q U E R Y R E S U L T S :
SO R T M ETH O D
sort({field1: sortOrder, field2: sortOrder, …, fieldn: sortOrder});
The sort method orders the documents from a collection according to the
specified fields.
Ø The sortOrder is specified as 1 (ascending) or -1 (descending) and is evaluated
from left to right.

Query: Find the client information for clients who have a loan at
the Festival Walk branch. Order the result first by credit
rating descending and then by name ascending.
db.clients.find({'loans.branch': 'Festival Walk'},

MQL Notes

1. Sorting can only be performed on fields in the input documents, not on computed fields in a projection.
2. The sort method is always applied before the projection of the fields in the original document.
(1 and 2 do not apply to the $sort aggregation stage discussed later.)
3. Documents in which the sort field is null or absent appear as the smallest values in the sort order.

S C H E M A V A L ID A T IO N
l

MongoDB uses JSON Schema to specify field validation rules,
such as allowed data types and value ranges.
– A JSON Schema is defined using the $jsonSchema keyword.

l

The data type of a field is specified using the bsonType (binary
JSON) keyword.
– Some common valid BSON data types are array, binData, bool,
date, decimal, double, integer, long, null, object, regex and string.

l

Schema validation can be specified either before or after a
collection is created.
– This allows for flexible initial collection creation with no validation.
