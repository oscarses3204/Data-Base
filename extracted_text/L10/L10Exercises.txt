tuples in OrderDetails (e.g., one order may contain several different books).

EXERCISE 7
Find each book's rank with respect to the total number of books sold.
Include in the query result tuples attributes title,
author name (first followed by last) and book rank.
Order the query result tuples first by rank ascending
and then by title ascending.
select title, firstName || ' ' || lastName as author,

from Author natural join Book natural left outer join OrderDetails
group by title, firstName, lastName, bookId
