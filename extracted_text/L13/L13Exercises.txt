EXERCISE 3
Find sailors between 20 and 30 years old who have not reserved any boat.
Include in the query result objects fields sailor name, age and rating.
Is this a
correct
solution?

Query result: {sName: 'Andy', age: 25, rating: 8} {sName: 'Amy', age: 25, rating: 3}

db.sailors.find({age: {$gte: 20}, age: {$lte: 30}, reservations: {$exists: false}},
{_id: 0, sName: 1, age: 1, rating: 1});

No! Why?

Query {sName: 'Emily', age: 16}
{sName: 'Zoey', age: 17, rating: null}
result: {sName: 'Andy', age: 25, rating: 8} {sName: 'Zorba', age: 16, rating: 1}
{sName: 'Amy', age: 25, rating: 3}

{sName: 'Rachael', age: 17, rating: 10}

The implicit and condition has two predicates on the same field age.
Only the last predicate is applied!

db.sailors.find({$and: [{age: {$gte: 20}}, {age: {$lte: 30}}, {reservations: {$exists: false}}]},
{_id: 0, sName: 1, age: 1, rating: 1});
db.sailors.find({age: {$gte: 20, $lte: 30}, reservations: {$exists: false}},
{_id: 0, sName: 1, age: 1, rating: 1});
Use either $and operator or a list of conditions
when conjunctive predicates are on the same field.

EXERCISE 6
Find sailors who have reserved both boat 101 and boat 103.
Include in the query result objects fields sailor id, name and rating.
Is this a
correct
solution?

No! Why?

Query result: {sailorId: 22, sName: 'Dustin', rating: 7}

db.sailors.find({'reservations.boatId': 101, 'reservations.boatId': 103},
{_id: 0, sailorId: 1, sName: 1, rating: 1});
Query {sailorId: 22, sName: 'Dustin', rating: 7}
result: {sailorId: 31, sName: 'Lucy', rating: 10}

{sailorId: 74, sName: 'Horatio', rating: 9}

☞ Sailors who have reserved boat 103.
The implicit and condition is on the same field reservations.boatId.

☞ Only the last predicate is applied!

db.sailors.find({'reservations.boatId': {$eq: 101, $eq: 103}},
{_id: 0, sailorId: 1, sName: 1, rating: 1});
The same result as above since an implicit and condition, when applied to
array fields, is evaluated differently than when applied to non-array fields.
(See next lecture.)
