Why is the floor and not the ceiling function used in the calculations?
If we use the ceiling function, then, for the 3rd level, the number of pages would
be ⌈3,125 / 8⌉ = ⌈390.63⌉ = 391.
In this case, the last node would hold only 3,125 - (390*8) = 3,125 – 3,120 = 5
pointers (4 values), which is less than the minimum required occupancy. Thus,
when using the floor function, every B+-tree node at this level, except the last
one, would hold 8 pointers (7 values) while the last one would hold 8 + 5 = 13
pointers (12 values), maintaining the minimum occupancy requirement.
For the root node, however, the ceiling function is used since the root node is not
required to follow the minimum occupancy requirement, and we need to point to
the nodes at the next level.
